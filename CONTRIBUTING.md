# Contributing

Small fixes, compatibility reports, and original pet packs are welcome.

## Copyrighted assets

Do not upload or link to unauthorized copyrighted audio, artwork, game files,
or extracted assets. Comments containing those materials may be edited or
removed.

Contributed pet packs must contain only assets you created or have permission
to distribute. State the asset license in the pack directory.

## Checks

Run before opening a pull request:

```zsh
./test
```

Do not include personal Codex or Claude configuration, completion payloads,
conversation text, credentials, or absolute paths from your machine.
